Ninja LegaCy

Ninja LegaCy là một game hành động – phiêu lưu 2D được phát triển bằng Unity, nơi người chơi điều khiển một ninja chiến đấu với quái vật, thu thập vật phẩm và hoàn thành nhiệm vụ qua các màn chơi.

📌 Thông tin dự án

Engine: Unity

Unity Editor: 2022.3.62f2 (LTS)

Thể loại: 2D Action / Adventure

Nền tảng: PC (Windows) – có thể build cho macOS & Linux

🎮 Lối chơi

Hoàn thành nhiệm vụ trong từng màn chơi

Tiêu diệt quái vật

Thu thập vật phẩm, nâng cấp kỹ năng và nhân vật

Quản lý năng lượng khi sử dụng kỹ năng

⌨️ Điều khiển (mặc định)
Hành động	Phím
Di chuyển	← → hoặc A / D
Nhảy	Space
Tấn công	J hoặc Chuột trái
Kỹ năng / Hành động phụ	K / L

Các phím có thể thay đổi trong cấu hình game.

🛠 Yêu cầu hệ thống

Unity Editor: 2022.3.62f2 (LTS)

Hệ điều hành:

Windows (khuyến nghị)

macOS / Linux (nếu build tương thích)

▶️ Chạy dự án

Mở Unity Hub → Add Project

Chọn thư mục dự án: 07_Ninja_LegaCy

Mở scene chính trong:

Assets/Resources/MyGame/Scenes


(thường có tên chứa Main)

Nhấn Play để chạy thử trong Editor

📦 Build game

Vào File → Build Settings

Thêm scene chính vào Scenes In Build

Chọn nền tảng: PC, Mac & Linux Standalone

Nhấn Build

📁 Cấu trúc thư mục chính
Assets
├── Resources
│   └── MyGame
│       ├── Scripts      # Player, Enemy, UI, Game Logic
│       ├── Scenes       # Các scene của game
│       └── Prefabs
├── Game Resources       # Sprites, âm thanh, fonts
